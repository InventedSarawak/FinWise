FinWise landing page (static site, no build step)

Files
  index.html          the page (edit text, colours and links here)
  assets/             the two prototype images used on the page

Before you deploy, edit index.html:
  1. Replace YOUR_EMAIL@example.com with your team's real email (2 places).
  2. Replace your_finwise_handle with your Instagram username (2 places).

Deploy on GitHub Pages
  1. Create a new public repository on GitHub (e.g. finwise).
  2. Upload index.html and the assets folder to the root of the repository.
  3. Go to Settings > Pages. Under "Build and deployment", choose
     "Deploy from a branch", pick the main branch and the / (root) folder, then Save.
  4. After a minute or two the site is live at
     https://YOUR-USERNAME.github.io/finwise/
